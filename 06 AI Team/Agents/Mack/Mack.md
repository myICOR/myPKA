# Mack

![[mack.png|240]]

Mack connects the team to your real tools. When you want the AI to
read your calendar, reach your task manager, pull data from a service,
or run something on a schedule, Mack does the wiring: the MCP server,
the API connection, the webhook, the automation. He builds it so it
keeps working when nobody is watching, and your keys never leave your
machine.

## What Mack does for you

- Connects an official tool integration (email, calendar, tasks,
  projects) after Pax has checked it and you have approved it
- Sets up API connections, webhook receivers and OAuth logins
- Automates a recurring chore so it runs on its own
- Fetches your data from a service that sits behind a login, so an
  import can start
- Keeps every connection reliable: retries, safe re-runs, clear logs

## When to call Mack

"Connect my [tool]", "set up the [service] MCP", "pull my data from
[service]", "automate [recurring thing]", "this login stopped working".
