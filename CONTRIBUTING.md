# Contributing to myPKA

This repository does not take pull requests. Bugs and ideas go to the ICOR for Life community at https://myicor.com.

## License

myPKA is MIT from 7.0.0, as `LICENSE-MAP.md` explains. You may copy, adapt and share it on those terms, in your own copy or fork.

## Security problems

Never report a security problem in a public issue or post. Report it privately as `SECURITY-myPKA.md` describes. What we do with the personal data in a report: https://myicor.com/privacy#github.
